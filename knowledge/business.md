# 사업·재무·시장 분석 일반 지식 (참고용. 과제 자료·담당자 답이 항상 우선)

표기: [질문] 담당자에게 물을 것. 일반론이라 확인 전까지 [일반]. 외부 숫자를 이 파일에서 만들지 않는다.

## 1. 손익 지표
- 매출 → (매출원가) → 매출총이익 → (판매·관리비, 연구개발비) → 영업이익 → 순이익. 이익률 = 이익 / 매출
- 비교 기준: 전 분기 대비, 전년 같은 분기 대비, 누적. 어느 기준인지 표마다 표시
- 일회성 항목·회계 기준 변경이 있으면 따로 표시 [질문]

## 2. 시장 지표
- 시장 규모, 점유율(분모가 매출 기준인지 물량 기준인지 [질문]), 성장률, 연평균 성장률
- 물량 단위가 산업마다 다르다(개수·용량·면적 등) [질문]
- 평균 판매 가격 = 매출 / 물량. 매출 변화 = 가격 효과 + 물량 효과(+ 구성 효과)로 나눠 설명할 수 있다
- 수요처(산업·고객군)별 비중, 계절성, 재고 수준(재고 일수), 가동률, 설비 투자

## 3. 가치사슬
- 일반 흐름: 원재료·소재 → 장비·부품 → 설계 → 제조 → 조립·완제품 → 유통 → 최종 고객. 단계마다 주요 지표(원가·품질·납기·가격)와 위험(공급 집중·가격 변동·기술 변화)
- 회사 안의 기능: 연구개발, 구매, 생산, 품질, 영업·마케팅, 지원(재무·인사). 질문을 받으면 어느 단계·기능의 질문인지 먼저 정한다
- 한 단계의 변화가 다음 단계로 전달되는 시차가 있다(예: 수요 변화 → 재고 → 가격). 시차는 데이터로 확인 [질문]

## 4. 비교·리포트 주의
- 회사마다 회계 연도·분기 끝, 사업 부문 나눔, 통화가 다르다 → 맞추거나 주석
- 실적(발표값)·추정치·회사 전망을 섞지 않는다. 값마다 종류와 발표일
- 수정된 값이 있으면 최신 판 기준을 명시
- 해석 문장은 근거 숫자와 같이 쓰고, 인과는 "가능성" 수준으로

## 5. 설명·교육용으로 쓸 때
- 용어는 쉬운 비유 + 정확한 정의 + 출처. 비유가 정의를 틀리게 만들면 비유를 버린다
- 학습자 수준별로 같은 개념을 다른 깊이로. 확인 문제는 정답 근거가 자료 안에 있어야 한다
