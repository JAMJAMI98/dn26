# knowledge — 일반 배경 지식 (키트 폴더에만 있고 작업 폴더로 복사하지 않는다)

쓰는 법: kickoff에서 과제 분야가 맞는 파일의 **필요한 절만** 읽는다. 전부 읽지 않는다.
- 여기 내용은 담당자에게 물을 **질문 거리**와 데이터 함정 후보다. 과제 README·데이터·담당자 답이 항상 우선이다.
- 문서·코드에 옮길 때는 [일반]으로 표시하고, 담당자 답으로 확인되면 출처를 바꾼다. 여기서 숫자 기준을 가져오지 않는다.
- 더 나은 방법이 보이면 이 파일에 얽매이지 않는다.

| 파일 | 언제 |
|---|---|
| manufacturing.md | 생산·설비·공정·계측·수율·설비 상태 데이터가 나올 때 |
| quality.md | 검사·불량·변경 검토·공급처 평가·위험 평가가 나올 때 |
| business.md | 손익·시장·가격·수요·가치사슬, 설명·교육 자료가 나올 때 |
