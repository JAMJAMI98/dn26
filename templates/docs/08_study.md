# 08 설명 카드 (G5에서 사용자가 읽는다 — 사람 말로, 파일:함수·숫자 포함)
1. 핵심 결정: 무엇을 왜 택했나 / 대안과 차이 / 포기한 것
2. 전체 구조: 입력이 저장·선택되는 곳 → 계산 → 검사 → 저장 → 조회. 모듈 책임과 상태 위치
3. 구현·검증한 것 vs 가정·미구현 / 다른 사람이 확인할 경로(명령·테스트·파일)
4. 실패 시나리오: 잘못된 입력, 동시 요청, 데이터 교체 직후 — 어떻게 동작하나
5. 설정을 바꾸면 결과가 어떻게 바뀌나(예측과 실측) / 가장 약한 곳 → 파급(누가 무엇을 잃나) → 다음 검증
6. AI 협업 사례(AI_COLLABORATION에 쓴 것): 담당자 확인 경로, AI 지적을 받아들인 것·고친 것·버린 것과 근거(명령·결과)
7. 핵심 결정 집중(질문이 몰릴 곳, 각 한 줄): 왜 / 버린 대안 / 약점과 파급 / 어떻게 확인 / 조건이 바뀌면 / AI가 한 것·내가 고친 것
8. 골격: 공개 키트에서 가져온 것(인증·역할·작업 잠금·오류 형식·배포)과 이번에 쓴 것(업무 로직·화면)의 경계, 골격이 왜 그렇게 동작하는지 한 줄씩
9. 보안: 골격이 해 준 것 / 이번에 점검·수정한 것 / 남은 한계 (각 한 줄)
