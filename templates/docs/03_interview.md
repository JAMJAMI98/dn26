# 03 담당자 Q&A (질문 하나 = 바뀌는 결정 하나)
| # | 회차 | 보낸 시각 | 질문 | 답 (원문) | 바뀐 결정 (docs/05 D번호) |
|---|---|---|---|---|---|
| 1 | 1차 | | | | |
- 1차(+10~20) 4~5개: 좋고 나쁨의 기준 / 넘으면 안 되는 숫자(꼭인가 가능하면인가) / 상충 시 우선순위 / README가 "담당자에게 확인"이라 한 것·데이터 설명의 해석 문구 / 예외 처리
- 2차(+40~50) 2~3개: 데이터에서 찾은 구체 사례("이런 행이 N건, 업무상 어떻게 보나요?")

- 묻지 않는 것: 파일로 계산 가능한 숫자, 구현 방법·정답, 이미 답한 것
