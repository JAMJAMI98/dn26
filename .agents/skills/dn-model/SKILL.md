# 예측·분류·이상 탐지 (domains/<문제>/{features,model,evaluate}.py)

1. **목표와 비용**: 무엇을 맞히나, 틀리면 무엇이 비싼가(놓침 vs 헛경보) → 지표 선택(재현율·정밀도·F1·PR-AUC·MAE 등)과 임계값 기준을 담당자 질문으로 확인.
2. **분할**: 시간 순서가 있으면 시간으로 나눈다. 같은 개체(설비·로트)가 학습·평가에 섞이지 않게. 누수 열(결과 이후에 생기는 값) 점검.
3. **기준선 먼저**: 다수 클래스·이전 값·단순 규칙 → 그다음 이미 설치된 라이브러리의 단순 모델(로지스틱, 트리 계열). 새 의존성은 승인 후. 설치가 막히면(B안) 표준 라이브러리로: 규칙·이동평균·임계값·나이브 베이즈 같은 기준선과 지표(재현율·정밀도·MAE)를 직접 계산하고, 그 한계를 docs/07에 적는다.
4. **실험 표**(docs/06): 모델·특징·파라미터 / 지표 / 기준선 대비 / 실행 시간. 같은 분할·같은 지표로만 비교. 난수 시드 고정.
5. **설명**: 중요 특징 상위 몇 개, 틀린 사례 몇 개를 사람이 볼 수 있게. 화면에는 확률보다 판단과 근거를.
6. **임계값**: 업무 비용 기준으로 정하고 결정 표(docs/05)에 근거.
## 시간 순서로 측정되는 품질·공정 값(관리도형 모니터링)
- 그룹을 먼저 나눈다: 장비·라인·제품·측정 위치별 분포가 다르면 섞어서 한계를 잡지 않는다(그룹별 평균·산포 표부터).
- **관리 한계**(안정 구간에서 추정한 평균 ± 3σ)와 **규격 한계**(업무 기준, 담당자가 준다)는 다르다. 섞지 않고 둘 다 표시한다.
- 이상 판정 규칙(한계 밖 1점, 같은 쪽 연속 N점, 연속 증가·감소 N점 등) 중 무엇을 쓸지와 N은 담당자에게 확인하고 설정값으로 둔다.
- 공정능력 지수(Cp·Cpk)는 규격 한계가 있을 때만, 분포 가정을 함께 적는다.
- 정비·교체·조건 변경 기록이 있으면 그 시점 전후를 나눠 본다(변화점).
- 화면: 시간 축 + 한계선 + 판정 근거(어느 규칙에 걸렸나) + 다음 조치는 담당자 규칙으로.

7. **검증**: 독립 재계산(창 B)으로 지표 하나를 다시 계산, 학습 데이터가 평가에 섞이지 않았음을 테스트로.
