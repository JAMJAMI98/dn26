# 분석 리포트·대시보드형 (계산은 창 A, 재계산 대조는 창 B)

1. **질문 먼저**: 이 결과로 누가 어떤 결정을 하나 → 답해야 할 질문 3~5개를 docs/01에. 질문마다 필요한 지표를 붙인다. 질문에 안 쓰이는 지표는 만들지 않는다.
2. **지표 정의표**(docs/05): 이름 / 정의(분자·분모) / 단위 / 기간·집계 단위 / 출처(파일·열 또는 자료 이름·발표일) / 비교 기준. 같은 이름의 지표도 조직마다 정의가 다르니 담당자에게 확인한다.
3. **자료 출처표**(docs/04): 제공 자료가 우선. 제공되지 않은 사실이 필요하면
   - 담당자에게 자료·정의를 요청한다.
   - 플랫폼이 허용한 방법으로 얻었으면 출처·발표일·얻은 경로를 적고 [외부]로 표시한다.
   - 못 얻으면 [가정]으로 두고 그 가정이 결론을 얼마나 바꾸는지 적는다.
   - AI의 일반 지식에서 나온 숫자는 쓰지 않는다.
4. **맞추기**: 기간 경계(월·분기·회계연도), 단위(천·백만, 통화, 환산 기준일), 같은 대상의 이름 표기, 나중에 고쳐진 값(어느 판 기준인지 명시). 비교 대상끼리 정의가 다르면 맞추거나 표 아래에 주석.
5. **계산은 한 곳**: `domains/<문제>/metrics.py`(또는 `backend/scripts/`) 순수 함수. 표·차트·문장이 모두 이 결과를 쓴다. 문서나 화면에 숫자를 손으로 쓰지 않는다.
6. **사실과 해석 분리**: 절마다 "데이터가 보여 주는 것(숫자·출처)" → "해석(가설과 근거의 강도)" → "결정에 주는 의미". 인과를 단정하지 않는다.
7. **차트**: 차트 하나 = 질문 하나. 제목은 결론 문장. 축·단위·기간·출처를 표시하고, 비교는 같은 축에서.
8. **검증**(`$dn-verify`와 함께): 대표 숫자 3개를 원자료에서 다른 방법으로 재계산해 일치 / 구성비 합 100% / 기간 경계 사례 / 출처 없는 숫자 0(숫자가 있는 문장을 훑어 출처 확인).
9. **G2에서 정할 것**(API 대신): 질문 목록, 지표 정의표, 리포트 목차 또는 대시보드 블록, 자료 공백과 처리 방법.
10. **형태**: 역할·데이터 교체·조회가 필요하면 서비스 골격 위 대시보드. 아니면 과제가 정한 형식(마크다운·HTML·CSV) 결과 파일 + 그것을 다시 만드는 스크립트 하나(`make report`).
